#DATA TRANSFORMATION AND FEATURE ENGINEERING

## Overview

This project demonstrates basic data transformation and feature engineering techniques using a property dataset. The goal is to create meaningful features and prepare data for analysis.

## Concepts Covered

* Feature Engineering
* Datetime Conversion
* Month Extraction
* Outlier Detection using IQR

## Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook

## Dataset

The dataset contains property details such as property ID, price, size, listing date, and year built.

## Outcome

Successfully transformed raw property data by creating new features, processing date columns, and identifying potential outliers for further analysis.
